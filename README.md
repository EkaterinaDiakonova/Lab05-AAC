## Итоговый вопрос
Вопрос: Почему процессору может быть выгодно загрузить из оперативной памяти сразу целый блок соседних данных, а не только один нужный элемент?
Ответ: Потому что данные в памяти лежат рядом, и при загрузке целой кэш-линии процессор с высокой вероятностью скоро попросит и соседние элементы. Загрузив блок сразу, процессор экономит время на последующих обращениях к памяти.
